지원 형식 안내 ↗

Mac 앱에서 이어가기

  1. Habitude를 최신 버전으로 업데이트합니다.
  2. 설정 → 다른 노트 앱에서 가져오기에서 원본 앱과 내보낸 파일을 선택합니다.
  3. 제목·날짜·주의 사항을 미리 본 뒤 가져오기를 누릅니다.

현재는 텍스트 교환 초기 배포입니다. 첨부가 포함된 내보내기는 중단하며 사진 백업·실시간 양방향 동기화를 제공하는 것으로 표시하지 않습니다. GitHub 다운로드 배포와 각 앱의 마켓플레이스 심사는 별개입니다. Notion 공개 OAuth 앱은 아직 등록·승인되지 않았습니다.
