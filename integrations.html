  3. 미리 보고 가져오세요제목·날짜·주의 사항을 확인한 뒤 가져오기를 누르세요. 원래 앱의 글은 보존됩니다.

한 번에 파일 20개·기록 100개·총 8 MiB까지. 현재 파일 가져오기는 텍스트 전용이며, 첨부가 포함된 내보내기는 가져오기를 중단합니다.

Notion 연결은 어떻게 설정하나요?

내 Notion 워크스페이스에 읽기 전용 내부 연결을 만들고, 가져올 페이지만 공유하세요. Habitude Mac → 설정 → Notion 연결에 토큰을 입력하면 Mac 키체인에 저장됩니다.

페이지 링크를 최대 20개 입력하고 미리 본 뒤 가져오세요. 현재는 Mac 개인 연결이며, 공개 OAuth 앱이나 Notion Marketplace 등록 앱은 아닙니다.

템플릿 ZIP에는 일일 기록·습관·주간 회고 Markdown이 들어 있습니다. Notion의 텍스트 및 Markdown 가져오기로 열어 사용하세요. 자동 수식이나 반복 작업은 포함하지 않습니다.

어떤 기능과 설치 경로를 지원하나요?
  • Joplin·Logseq는 다운로드하여 직접 설치할 수 있습니다. Logseq Marketplace 등록 요청은 제출되었으며, 승인은 대기 중입니다.
  • Logseq의 DB 그래프·Org 형식은 지원하지 않습니다. Note Clipper는 미리 보기 버전이며 Chrome 웹 스토어에 등록되지 않았습니다.
  • 현재 연동은 사용자가 확인하는 텍스트 가져오기입니다. 실시간 양방향 편집이나 사진·첨부 백업은 제공하지 않습니다.
원본과 가져온 기록은 어디에 보관되나요?

원본 앱의 글은 수정하지 않습니다. 가져온 글은 Habitude에서 선택한 로컬 저장소 또는 Obsidian Vault에 저장됩니다. 같은 원본을 다시 가져오면 중복과 로컬 수정·이동·삭제를 확인합니다.

파일 가져오기는 Mac에서 처리합니다. 계정의 클라우드 동기화를 켠 경우, 이후 동기화에는 해당 계정의 설정이 적용됩니다.

문제 신고에는 재현용 예시만 첨부해 주세요. 개인 기록과 연결 토큰은 포함하지 마세요.
